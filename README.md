# Classification Models – Week 2

This practice set focuses on basic Classification Models using Python and Scikit-learn.

## Topics Covered

- Logistic Regression
- Confusion Matrix
- Accuracy Score
- Decision Tree classifier
- k-Nearest Neighbour(KNN)
- Decision Tree `max_depth` tuning

## Dataset

Titanic Dataset

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Practice Questions

1. Train a Logistic Regression model on the Titanic dataset.
2. Create a Confusion Matrix and calculate Accuracy Score.
3. Compare Decision Tree Classifier and KNN Classifier accuracy.
4. Tune the `max_depth` of Decision Tree and observe the difference in accuracy.

## Conclusion

This practice set demonstrates the implementation and evaluation of different classification models using the Titanic dataset.
